الحل الأسهل دلوقتي (ملف واحد فقط)
==========================================

الملف "index.html" الموجود في نفس المجلد ده هو التطبيق كامل
(الـ CSS والـ JavaScript مدمجين جوه الملف، حجمه حوالي 1.4 ميجا).
اتاختبر في المتصفح وبيفتح بدون أي أخطاء ✅

الخطوات:
1) افتح https://github.com/hanyfahm/pharma3
2) ادخل على ملف index.html الموجود في جذر الريبو واضغط على أيقونة القلم ✏️ (Edit).
3) امسح كل المحتوى القديم، والصق مكانة محتوى ملف index.html الموجود في المجلد ده.
   (أو احذفه وارفع ملف الـ index.html ده بنفس الاسم).
4) اكتب رسالة commit زي: "Fix GitHub Pages app" واعمل Commit.
5) استنى دقيقة أو اتنين، وبعدين افتح:
   https://hanyfahm.github.io/pharma3/

لا تحتاج تعمل Actions ولا ترفع مجلد src ولا تحط إعدادات Pages.
الإعداد الحالي (Deploy from branch) هيخدم الملف مباشرة.

ملاحظة: على النسخة دي البيانات بتتخزن في متصفحك أنت (localStorage)،
مش قاعدة مشتركة بين الفريق. ده طبيعي لأن GitHub Pages استاتيك.
